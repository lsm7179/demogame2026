# OpenAI Game 2026 Workspace

브라우저 게임 프로토타입을 폴더별로 관리하는 저장소입니다.

## Games

- `echo-breach/`: 타임루프 탑다운 액션 슈터. GitHub Pages 공개 대상입니다.
- `signal-keeper/`: 도시 신호 복구 프로토타입. 형상관리만 하며 Pages에는 배포하지 않습니다.

## GitHub Pages

`.github/workflows/pages.yml`은 `echo-breach/` 디렉터리만 Pages artifact로 업로드합니다. `signal-keeper/` 파일은 저장소에는 포함되지만 공개 사이트 산출물에는 포함되지 않습니다.

공개 주소: https://lsm7179.github.io/demogame2026/echo-breach
