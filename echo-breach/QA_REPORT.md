## 발견한 위험

### P1 — 유지보수하기 어려운 압축 소스

`game.js`와 `style.css`가 소수의 매우 긴 라인으로 구성되어 있다. 동작에는 문제가 없지만 diff 검토, 충돌 해결, 버그 위치 파악과 코드 리뷰가 어렵다. 기능 확장 전에 동작을 바꾸지 않는 포맷팅 커밋을 별도로 만드는 것을 권장한다.

### P1 — 자동 회귀 테스트 부재

Echo 기록·재생은 시간과 상태에 민감하지만 자동 테스트가 없다. 최소한 저장 데이터, 난이도 설정, 랭크 계산과 기록 보간을 순수 함수로 분리해 테스트할 필요가 있다.

### P1 — Stage 1~3 완주 검증 필요

메뉴와 전투 부팅은 확인했지만 실제 완주와 업그레이드 조합은 아직 검증하지 않았다. 공개 배포 전 사람이 각 난이도로 체크리스트를 수행해야 한다.

### P2 — 접근성 보강 필요

Canvas 전투는 시각 효과 중심이며 모션 감소 설정, 키보드 포커스 스타일과 색각 보조 표현을 추가 검토해야 한다.

### P2 — 출시 메타데이터 부재

favicon, Open Graph 이미지, 게임 버전 표시, 라이선스 문서와 변경 기록이 아직 없다. 게임 플레이가 안정된 뒤 릴리스 준비 단계에서 추가한다.
