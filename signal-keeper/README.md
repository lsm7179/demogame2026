# Signal Keeper

브라우저에서 index.html을 열어 실행하는 3분짜리 도시 전력망 관제 게임입니다.

## 조작

- 구역 선택: 클릭/터치 또는 1, 2, 3
- 전력 이동: Q(회수), E(배정), 또는 하단 버튼
- 주파수 미니게임: 화면 탭/클릭 또는 Space

## 출시 전 수동 QA

- [ ] 시작과 재시작, Enter가 정상 동작한다.
- [ ] 클릭, 1/2/3, Q/E, 하단 버튼, 모바일 터치가 각각 동작한다.
- [ ] 30초 이후 2개, 마지막 30초에 최대 3개 사건이 보인다.
- [ ] 전력 배정 부족/과잉, 전환 지연, 과부하 100%를 확인한다.
- [ ] 각 구역 실패 효과와 특별 위기, 두 미니게임을 확인한다.
- [ ] localStorage가 차단돼도 결과 화면이 열린다.

## 정적 검사
